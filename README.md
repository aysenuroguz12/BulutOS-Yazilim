# web-odevi

Bu proje, BulutOS Yazılım A.Ş. için hazırlanan tek sayfalık bir web sitesi örneğidir. Proje, akıllı cihaz ve IoT ekosistemi için yazılım lisansı, ürünler, fiyatlar, ekip yapısı ve iletişim bilgilerini tanıtan bir landing page tasarımını içerir.

## Proje Hakkında

Bu uygulama, HTML ve CSS kullanılarak oluşturulmuş statik bir web sayfasıdır. Site içeriği, şirket tanıtımı, misyon-vizyon açıklamaları, ürün ve hizmetler, ekip yapısı, fiyat listesi ve iletişim bölümünden oluşur.

## Kullanılan Teknolojiler

- HTML
- CSS
- Google Fonts

## Proje Yapısı

- `index.html` - Ana web sayfası
- `README.md` - Proje açıklamaları

## Nasıl Çalıştırılır?

1. Proje klasörünü bilgisayarınıza indirin.
2. `index.html` dosyasını bir web tarayıcısında açın.

Örnek:

```bash
cd web-odevi
```

Ardından `index.html` dosyasını açarak siteyi görüntüleyebilirsiniz.

## Özellikler

- Mobil uyumlu tasarım
- Sticky menü ve sayfa içi navigasyon
- Hakkımızda, misyon-vizyon, ekip ve ürün bölümleri
- Fiyat tablosu ve iletişim alanı
- Modern ve sade arayüz
