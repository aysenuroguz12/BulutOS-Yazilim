# web-odevi

Bu proje bir web geliştirme ödevi projesidir.

## Proje Hakkında

Bu repository, web tasarımı ve geliştirme becerilerinin gösterildiği bir HTML projesidir.

## Kullanılan Teknolojiler

- HTML

## Proje Yapısı

Proje temel HTML dosyaları içermektedir.

## Kullanım

1. Repository'yi klonlayın:
```bash
git clone https://github.com/aysenuroguz12/web-odevi.git
```

2. Proje klasörüne gidin:
```bash
cd web-odevi
```

3. HTML dosyalarını bir web tarayıcısında açın.

## Dosyalar

Bu proje, web ödevi için gerekli HTML dosyalarını içermektedir.
